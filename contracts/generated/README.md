# Generated Felony verifier

`UltraHonkVerifier.fe` is generated from the current Noir circuit using `barretenberg_fe`. Compile it with Fe 26.6.0 in standalone mode; its constructor also deploys RelationsLib. The generated source is separate from the game contracts.

See [verifier generation](../../README.md#regenerate-the-verifier). `manifest.json` records its circuit/key/source provenance. Regenerate after circuit changes; do not hand-edit the generated verifier.
